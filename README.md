# ZZA — сетевые гонки в локальной сети

2D-гонки на 1–6 человек для локальной сети. Копия папки нужна только одному —
остальные заходят из браузера по его IP.

---

## Запуск

Один компьютер становится сервером:

```
python3 main.py
```

Скрипт поднимет сервер, откроет браузер и напечатает адрес:

```
  Играть с других компьютеров:

      http://192.168.1.42:8000
```

Этот адрес и нужно назвать остальным. У них ничего устанавливать не надо:
открыли браузер, набрали адрес — и они в меню. Тот, кто запустил `main.py`,
играет наравне со всеми, просто у него в лобби есть кнопка «Начать заезд».

### Tornado

Единственная зависимость. Положите папку `tornado` рядом с `main.py` или в
подпапку `vendor/` — скрипт найдёт её сам. Либо `pip3 install tornado`, если
интернет есть.

Проверено на Python 3.11 и Tornado 6.5.

### Ключи

```
--port 8000        другой порт
--no-browser       не открывать браузер (для выделенной машины)
--host 127.0.0.1   слушать только себя
--snapshot-hz 20   реже слать состояние, если сеть окажется узкой
```

## Управление

| | |
|---|---|
| Газ / тормоз | `↑` `↓` или `W` `S` |
| Руль | `←` `→` или `A` `D` |
| Ручник (занос) | `Shift` |
| Применить бонус | `Пробел` или `Ctrl` |
| Вернуться на трассу | `R` |
| Пауза | `Esc` |
| Диагностика | `F3` |
| Настройка физики (хозяину лобби) | `F4` |
| Во весь экран | `F11` или двойной щелчок по полю |

Вылетели с трассы — выбирайтесь сами, по траве медленно. Если встали и не
двигаетесь пару секунд, игра вернёт вас на последний чекпоинт.

## Режимы

**Гонка.** Создаёте лобби, называете остальным четырёхбуквенный код (или они
находят лобби в списке). Настройки: трасса, число кругов, до 6 игроков,
бонусы вкл/выкл, столкновения вкл/выкл, пароль. Пока идёт заезд, лобби видно
в списке с пометкой «идёт заезд» — зайти нельзя, но после финиша хозяин
жмёт «Ещё раз», и присоединиться можно к следующему.

**Заезд на время.** В одиночку, без бонусов и столкновений. Лучший круг
попадает в таблицу рекордов, которая живёт в `data/records.json` и переживает
перезапуск сервера.

## Если что-то пошло не так

**Никто не может подключиться.** Проверьте, что порт 8000 открыт на серверной
машине. Быстрая проверка с чужого компьютера: откройте
`http://адрес:8000/api/status` — должен прийти JSON. Если не приходит, дело в
сети или межсетевом экране, а не в игре.

**Пустой или странный экран.** Нажмите `F3`. Оверлей показывает fps, время
кадра, задержку, опережение сервера и работу предсказания. **Сфотографируйте
его** — по этой картинке видно, что именно не так.

Что смотреть:

| Строка | Норма | О чём говорит |
|---|---|---|
| `fps` | 60 | главный показатель |
| `длинных >20мс` | 0 | подёргивания; если растёт — машина не тянет |
| `выдача команд` | до 4 мс | время на выдачу команд рисования. Команды выполняются асинхронно, поэтому если эта цифра мала, а `fps` низкий — упирается видеоподсистема браузера, а не игра |
| `качество` | 2 | 0 или 1 — игра сама снизила качество, машина не тянет |
| `задержка` | до 5 мс | круговая задержка до сервера |
| `запас ввода` | 2–5 | меньше нуля — ввод не успевает к своему тику |
| `поправок` | единицы процентов | много — клиент и сервер считают по-разному |
| `пересборок` | 1 | больше — клиент не успевает за сервером |

**Тормозит.** Игра сама снижает качество (отключает траву, частицы, декор),
если кадры перестают укладываться. Уровень виден в `F3`.

## Настройка ощущения машины

Подобрать разгон, сцепление и занос «на бумаге» невозможно, а возить правки
на флешку долго. Поэтому: хозяин лобби жмёт `F4` и крутит ползунки **прямо во
время заезда** — физика меняется сразу у всех. Когда понравилось, кнопка
«Скачать physics.json» отдаёт готовый файл. Положите его в `shared/physics.json`
на серверной машине — это станет новой настройкой по умолчанию.

## Как это устроено

Сервер авторитетный. Симуляция идёт фиксированным шагом 60 Гц и у сервера, и у
клиента, снапшоты уходят реже — 30 раз в секунду.

Клиент **предсказывает свою машину сам**, не дожидаясь ответа сервера: иначе
руль отзывался бы с задержкой. Когда приходит снапшот, состояние откатывается
к авторитетному и переигрывается вперёд на сохранённых вводах.

Чтобы это работало, физика Python и JavaScript должна совпадать **побитово**.
Поэтому:

* `shared/carstep.py` и `static/js/game/carstep.js` — зеркальные файлы;
* используются только `+ - * / sqrt` и собственные `fsin`/`fcos` (полином
  вместо `math.sin`, который может отличаться в последнем бите);
* `tools/crosscheck.py` прогоняет одинаковые вводы через обе версии и требует
  точного совпадения.

Благодаря этому при обычной езде поправка равна нулю — проверено на прогоне:
**1 поправка на 947 снапшотов**. Поправки появляются только там, где клиент и
не мог знать правды: столкновения, попадания, возврат на трассу. Столкновения
машин и бонусы клиент не предсказывает вообще — их считает только сервер, а
расхождение сглаживается за сотню миллисекунд, чтобы не было рывка.

Трасса рисуется процедурно каждый кадр из той же ломаной, по которой считается
физика. Пре-рендера в большую картинку нет: круг на 3–5 минут занял бы сотни
мегабайт. Побочная выгода важнее экономии — картинка и коллизии строятся из
одних и тех же точек и разъехаться не могут.

## Добавить трассу

Трасса — это JSON с опорными точками осевой линии. Движок сам развернёт их в
сплайн, посчитает ширину, покрытия, чекпоинты и расставит боксы с бонусами.

```json
{
  "id": "moya_trassa",
  "name": "Моя трасса",
  "theme": "day",
  "closed": true,
  "laps": 4,
  "offSurface": "grass",
  "difficulty": "средняя",
  "checkpoints": 10,
  "nodes": [
    {"x": 0, "y": 0, "w": 150, "s": "road"},
    {"x": 800, "y": 100, "w": 150, "s": "road"}
  ],
  "decor": [{"t": "tree", "x": 200, "y": 300}],
  "boxes": []
}
```

`w` — полная ширина дороги. `s` — покрытие: `road`, `sand`, `ice`, `boost`.
`offSurface` — что вокруг трассы. Темы: `day`, `night`, `desert`, `snow`.
Типы декора: `tree`, `bush`, `rock`, `tire`, `cone`, `sign`, `building`.
Пустой `boxes` означает, что движок расставит бонусы сам.

Положите файл в `shared/tracks/` и проверьте:

```
python3 tools/validate_track.py
```

Проверяются самопересечение дороги, резкость поворотов, ширина, длина круга,
декор на полотне и боксы вне дороги.

Опорные точки удобнее считать скриптом, а не подбирать руками. Надёжный способ
обойтись без самопересечений — задать форму в полярных координатах:
`r(угол) = R * (1 + сумма синусов)`.

## Добавить бонус

Движок реализует четыре примитива: `self` (эффект на себя), `projectile`
(снаряд вперёд), `trap` (предмет позади), `blast` (мгновенно по цели). Новый
бонус — строчка в `shared/powerups.json`, код трогать не нужно:

```json
{
  "id": "nitro", "name": "Нитро", "icon": "💨", "color": "#8ef",
  "kind": "self",
  "effect": { "accelMul": 2.8, "maxSpeedMul": 1.7, "duration": 2.0 },
  "weight": [1.0, 2.0, 3.0]
}
```

`weight` — как часто бонус выпадает лидеру, середине и последнему. Отстающим
имеет смысл давать сильное чаще.

## Проверка

```
python3 tools/check.py          всё, включая прогон в настоящем браузере
python3 tools/check.py --fast   без браузера, несколько секунд
```

Браузерный прогон поднимает сервер, открывает четыре независимых клиента,
проводит заезд и проверяет лобби, чат, круги, результаты, реванш и
возвращение в лобби после `F5`. Отдельно гоняется заезд на время, где
поправок предсказания быть почти не должно — это точная проверка того, что
физика клиента и сервера не разъехалась.
