# Рисовашки

Игра в рисование для локальной сети: один рисует загаданное слово, остальные
угадывают. Без интернета, без установки пакетов, без отдельного «сервера» —
каждый просто запускает один и тот же файл.

## Запуск

```
python3 main.py
```

Откроется браузер. Дальше:

- **Создать лобби** — вы становитесь хозяином, комната живёт в вашем процессе.
- **Лобби в сети** — список чужих лобби, найденных по локалке. Клик — и вы в игре.
- **Подключиться по адресу** — если поиск ничего не нашёл (см. про файрвол ниже),
  введите `IP:порт` хозяина, его видно у него на экране лобби.

Хозяин закрывает программу — комната исчезает. Это игра на посидеть, а не сервис.

## Что нужно на машине

- Python 3.11
- папка `tornado` рядом с `main.py` (интернета и `pip install` в сети нет)
- любой современный браузер, проверено на Firefox 143

## Порты

| Порт | Зачем |
|---|---|
| TCP 8770–8789 | сам сервер игры, занимается первый свободный |
| UDP 45789 | поиск лобби в сети (broadcast) |

Если UDP-broadcast в сети закрыт, поиск лобби работать не будет — останется
подключение по адресу вручную. Всё остальное от этого не страдает.

## Режимы

- **Угадайка** — один рисует загаданное слово, остальные угадывают в чате.
- **Обычно** — испорченный телефон: фраза, рисунок по ней, подпись к рисунку, снова рисунок.
- **Сэндвич** — фраза, потом только рисунки, а последний ход снова подпись словами.
- **Плагиат** — копируешь предыдущий рисунок, и времени на каждую копию всё меньше.

Три последних — альбомные: у каждого свой альбом, он ходит по кругу, каждый видит
только предыдущий шаг. В конце альбомы показываются всем по шагам, а потом их
можно полистать самому.

## Как играть

Хозяин лобби выбирает режим и настройки и жмёт «Начать». Нужно минимум двое.

Художник выбирает слово из трёх и рисует; остальные пишут догадки в чат.
Чем быстрее угадал — тем больше очков; художнику начисляют по тому, как быстро
его поняли. Угадавшие продолжают переписываться между собой, не спойлеря остальным.
Подсказками постепенно открываются буквы.

Свои слова можно вбить в настройках через запятую — тогда общий банк не используется.

В альбомных режимах настраивается длина альбома («Ходов в альбоме», 0 — по числу
игроков) и время на рисунок и на подпись. Чат во время хода закрыт, чтобы никто
не спойлерил, и открывается на показе.

Перезагрузка страницы и обрыв связи не выкидывают из игры: место, очки и холст
возвращаются.

## Что внутри

```
main.py            запуск: порт, браузер, сервер
app/server.py      HTTP и WebSocket
app/rooms.py       комнаты, игроки, настройки
app/discovery.py   поиск лобби по UDP
app/words.py       банк слов и сверка догадок
app/modes/         игровые режимы
static/            фронтенд, без сборки и без внешних библиотек
data/words.json    банк слов
docs/modes.md      какие режимы задуманы и что делаем дальше
```

Рисунок хранится не картинкой, а списком штрихов — поэтому он летит по сети
сотнями байт, отменяется по одному движению и одинаково перерисовывается у всех.
