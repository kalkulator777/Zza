# Дурак по локальной сети

Подкидной и переводной дурак для игры в одной LAN без интернета.
Сервер — Python 3 + tornado, клиент — обычная веб-страница (ванильный JS,
никаких CDN, сборки и внешних шрифтов).

## Запуск

Один компьютер играет роль сервера, остальные просто открывают браузер.

```bash
python3 server.py            # порт 8888
python3 server.py --port 9000
```

При старте сервер печатает адреса, которые нужно раздать игрокам:

```
Сервер «Дурак» запущен. Открывайте в браузере:
  http://localhost:8888/
  http://192.168.1.42:8888/   <- этот адрес давайте остальным
```

Игроки открывают этот адрес в Firefox — больше ничего ставить не нужно.

### Если порт не открывается с других машин

Дело в брандмауэре сервера:

```bash
sudo ufw allow 8888/tcp                                   # если используется ufw
sudo iptables -I INPUT -p tcp --dport 8888 -j ACCEPT      # иначе
```

### tornado без интернета

Достаточно, чтобы рядом с `server.py` лежала папка `tornado` — сервер
добавляет свой каталог в `sys.path` сам. Взять её можно так (на машине с
интернетом):

```bash
pip download tornado -d wheels          # получаем tornado-*.whl
unzip tornado-*.whl -d tornado_pkg      # wheel — это обычный zip
cp -r tornado_pkg/tornado /путь/к/durak/   # переносим папку рядом с server.py
```

Либо штатно: `pip install --no-index --find-links=wheels tornado`.
Скомпилированный модуль `speedups` не обязателен — без него tornado работает.

Подходит tornado 5.1 и новее (проверено на 6.5).

### Автозапуск (по желанию)

```ini
# /etc/systemd/system/durak.service
[Unit]
Description=Durak LAN server
After=network.target

[Service]
ExecStart=/usr/bin/python3 /opt/durak/server.py --port 8888
WorkingDirectory=/opt/durak
Restart=always
User=durak

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now durak
```

## Как играть

1. Ввести имя.
2. Создать комнату или войти в чужую — из списка либо по четырёхзначному коду.
3. Ведущий (тот, кто создал комнату) настраивает правила и жмёт «Начать партию».

Настройки комнаты:

| Параметр | Значения |
|---|---|
| Колода | 24 (9…Т), 32 (7…Т), 36 (6…Т), 52 (2…Т) |
| Игроков | 2–6 (но не больше, чем колода / 6) |
| Переводной | вкл/выкл |
| Подкидывают | все игроки / только соседи отбивающегося |
| Максимум карт в кону | 2–6 |

Управление за столом:

* Клик по карте — если ход единственный, он делается сразу.
* Если картой можно и отбиться, и перевести (или побить несколько карт) —
  карта поднимается, а нужное действие выбирается кнопкой или кликом
  по подсвеченной карте на столе. Escape снимает выбор.
* «Беру» — забрать карты, «Бито»/«Пас» — закончить свой ход.
  Если подкинуть нечем, пас ставится автоматически.

### Реализованные правила

* Козырь — нижняя карта колоды, она же видна под колодой.
* Первым ходит обладатель младшего козыря.
* Подкидывать можно только ранги, уже лежащие на столе; не больше, чем
  карт у защищающегося, и не больше потолка кона (по умолчанию 6).
* Перевод — только пока ни одна карта не отбита и только картой того же
  ранга; у следующего игрока должно хватать карт на всю атаку.
* Добор до 6 карт: сначала тот, кто начинал кон, отбивавшийся — последним.
* Кто остался с картами, когда у всех остальных их нет, — дурак.
  Если карты закончились у всех одновременно — ничья.

### Обрыв связи

Игрок опознаётся по токену в `localStorage`, поэтому F5, закрытая вкладка
или пропавший на минуту Wi-Fi не выкидывают из партии: соединение
восстанавливается само, а на столе всё это время видно «не в сети».
Кнопка «Выйти из комнаты» во время партии тоже сохраняет место — вернуться
можно по коду комнаты. Если игрок ушёл совсем, ведущий прерывает партию
и начинает новую.

Чтобы проверить игру вдвоём на одном компьютере, второе окно откройте
как `http://localhost:8888/?p=2` — параметр `p` даёт вкладке отдельную
сессию (иначе обе вкладки — это один и тот же игрок).

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

* `tests/test_engine.py` — правила: колоды, биение, подкидывание, перевод,
  добор, конец партии.
* `tests/test_server.py` — протокол по настоящим вебсокетам: комнаты,
  запрет чужих ходов, полная партия, реконнект, чат.

## Что внутри

```
server.py        сеть: комнаты, игроки, вебсокеты, раздача статики
engine.py        правила игры — чистая логика без сети, покрыта тестами
static/index.html, style.css, app.js    клиент
tests/           тесты
```

Состояние живёт в памяти процесса: перезапуск сервера — это конец всех
партий. Для игры в обед этого достаточно; если понадобится переживать
перезапуск, состояние комнат нужно будет сохранять на диск.
