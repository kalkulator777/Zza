# Гонки в браузере для локальной сети

Аркадные 3D-гонки на пятерых машинах и трёх трассах, до восьми игроков
в одной гонке, с бонусами в духе картинга. Рассчитаны на то, чтобы играть
в офисе в перерыве: один человек запускает один файл, остальные заходят
браузером по адресу и сразу играют.

## Что нужно

Только то, что уже есть на машинах:

- Python 3.11 и Tornado — на том компьютере, где запускается игра
- Firefox (или любой браузер с WebGL2) — у всех остальных
- Общая локальная сеть

Интернет не нужен вообще: three.js лежит в репозитории, ассетов нет
ни одного — вся графика и весь звук генерируются кодом.

## Как запустить

```bash
python3 run.py
```

Откроется браузер, а в консоли появится адрес, который надо продиктовать
коллегам — что-то вроде `192.168.1.42:8000`. Они заходят по нему и играют.
Ставить им ничего не нужно.

Полезные ключи:

```bash
python3 run.py --no-browser        # только сервер, без открытия браузера
python3 run.py --port 8080         # другой порт
python3 run.py --name "Комп Васи"  # как сервер будет виден соседям
python3 run.py --guest-rooms       # разрешить создавать комнаты всем
```

По умолчанию **создавать комнаты может только тот, кто запустил игру** —
он получает личную ссылку с токеном. Остальные могут заходить в уже
созданные комнаты. Ключ `--guest-rooms` снимает это ограничение.

Если в сети несколько запущенных игр, они находят друг друга сами
(UDP-маяк на порту 8001) и показывают соседей списком в главном меню.

## Управление

| Клавиша | Действие |
|---|---|
| W или стрелка вверх | газ |
| S или стрелка вниз | тормоз и задний ход |
| A, D или стрелки | руль |
| Пробел | занос (ручник) |
| E или Ctrl | применить бонус |
| C | камера: от третьего лица или из кокпита |
| Shift | взгляд назад |
| Tab | таблица позиций |
| F3 | счётчик кадров и нагрузки |
| Esc | меню |

Раскладка не зависит от языка ввода.

**Про занос.** Держать ручник в повороте выгодно: пока машину несёт,
копится заряд, и на выходе она получает ускорение. Чем дольше держали —
тем сильнее, три уровня, видно по цвету искр (синие, оранжевые,
фиолетовые). Это главный способ отыграть время у соперника.

## Бонусы

Подбираются из коробок на трассе, в руках держится один. Что выпадет,
зависит от места: лидеру достаётся оборона, отстающему — средства догнать.

| Бонус | Действие |
|---|---|
| Турбо | ускорение на 2,5 с |
| Ракета | наводится на ближайшего впереди, сбивает с траектории |
| Мина | сбрасывается позади |
| Щит | гасит одно попадание |
| Гроза | замедляет всех, кто впереди вас |

Любой бонус отключается галочкой при создании комнаты, как и все бонусы
разом. Там же настраиваются трасса, число кругов, столкновения и
зеркальный вариант трассы.

## Если тормозит

В меню есть пресет качества: низкое, среднее, высокое. На слабых машинах
(например, Intel N5105 со встроенной графикой) ставьте низкое — уменьшится
плотность декора и разрешение отрисовки. Проверить нагрузку можно клавишей
`F3`: там видно кадры в секунду, число вызовов отрисовки и треугольников.

Сервер и браузер можно держать на одной машине, но если она слабая,
лучше запускать сервер на отдельной: `python3 run.py --no-browser`.

## Как это устроено

Архитектура и все внутренние договорённости описаны в `DESIGN.md`.
Коротко: авторитетный сервер на Tornado крутит физику 60 раз в секунду
и рассылает состояние 20 раз в секунду; клиент предсказывает свою машину
локально и сверяется с сервером, чужие машины интерполирует. Физика
существует в двух реализациях, на Python и на JavaScript, и они совпадают
численно — за этим следит `tools/test_physics_parity.py`.

```
run.py              запуск: сервер, браузер, обнаружение в сети
server/             Tornado, комнаты, лобби, UDP-маяк
game/               протокол, физика, трасса, машины, бонусы, симуляция
content/            описания трасс и характеристики машин
static/             клиент: рендер, интерфейс, сетевой код, звук
tools/              проверки и инструменты разработки
```

Инструменты:

```bash
python3 tools/test_physics_parity.py   # сверка физики Python и JS
python3 tools/preview_track.py office  # сводка по трассе и рисунок в SVG
python3 tools/test_sim.py              # прогон гонки с ботами
python3 tools/smoke_test.py            # сервер плюс браузер, сквозная проверка
```
