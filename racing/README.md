# Гонки в браузере (LAN)

Проект в стадии проектирования. Пока здесь только вендоренная зависимость рендера.

## Целевое окружение

- Linux-машины в одной локальной сети, Intel N5105 (UHD Graphics, 24 EU)
- Из пакетов доступны только Python 3.11, Tornado и Firefox 143
- Интернет на машинах не предполагается: всё, что нужно, лежит в репозитории

## Зависимости

`static/vendor/` — three.js r180, минифицированная ESM-сборка.
Начиная с r15x сборка разбита на два файла, нужны оба:

- `three.module.min.js` — точка входа, импортирует `./three.core.min.js`
- `three.core.min.js` — ядро

Подключается через import map, без сборщика и без npm.
